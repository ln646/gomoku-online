# 五子棋 · 单机版（PWA 安卓应用）

无需联网、无需安装任何东西的单机五子棋小游戏，已 PWA 应用化 —— 可安装到安卓手机桌面，像原生 App 一样全屏离线运行。

## 📲 安装到安卓手机（推荐方式）

1. 手机浏览器（Chrome / Edge）打开：**https://ln646.github.io/gomoku-online/offline/**
2. 点击菜单里的 **「📲 安装到手机桌面」** 按钮（或浏览器菜单 → "添加到主屏幕"）
3. 完成后桌面出现"五子棋"独立图标，点开即全屏运行，**之后完全离线可玩**

> 安装需要 HTTPS 环境且完成一次首次加载；安装后不再依赖网络。
> iOS：用 Safari 打开链接 → 分享 → "添加到主屏幕"。

## 如何启动（电脑本地）

**方式一（最简单）**：直接双击 `index.html` 用浏览器打开即可玩（file:// 下 PWA 安装不可用，但游戏功能完整）。

**方式二**：本地起服务后访问 `http://localhost:端口`，可完整体验 PWA 安装：

```bash
npx serve .
```

## 游戏玩法

- **人机对战**：五档难度任选 + 先后手（执黑先行或执白后行）
  - **简单 / 中等 / 困难**：从新手练手到全盘评估、主动封堵
  - **🔥 地狱**：AI 主动构建双活三、四三等多路杀招，防守滴水不漏，几乎不可能取胜
  - **🌍 世界**：最高棋力——迭代加深 α-β 深度搜索、连冲四（VCF）必胜点计算、组合威胁评估，代表当前可实现的极限
- **双人同屏**：两个人轮流在同一台设备上落子，黑先白后
- **胜利条件**：任意一方率先在横、竖或斜方向连成五子即获胜；棋盘下满无人连五则为和棋
- **操作方式**：鼠标点击棋盘交叉点落子，手机/平板可直接触摸落子；`Esc` 键暂停 / 继续

## 对局中功能

| 按钮 | 功能 |
|---|---|
| ↩ 悔棋 | 人机模式撤销你与 AI 的最近一轮落子；双人模式撤销最后一手 |
| ⏸ 暂停 | 弹出暂停菜单（继续 / 重新开始 / 返回主菜单） |
| 🔄 重开 | 放弃当前对局重新开始 |
| 🔊 音效 | 开关落子与胜利音效 |

## 本地保存（localStorage）

- **进度自动存档**：对局中途关闭页面，重新打开后主菜单会出现「▶ 继续上局」
- **战绩统计**：分难度记录人机胜/负/和、连胜场次，以及双人对战的黑白胜负
- 终局后进度存档自动清除；战绩可随时在主菜单「清空战绩」

## 代码结构

```
gomoku-offline/
├── index.html   页面结构：开始界面 / 游戏主界面 / 暂停与结算弹层
├── style.css    界面样式（响应式，适配手机）
├── game.js      核心规则：棋盘、胜负判定（复用原联机版逻辑）
├── ai.js        AI 引擎：五档难度——棋型评分（简单~困难）、多路威胁构建（地狱）、α-β 深度搜索 + VCF（世界）
└── app.js       主逻辑：状态机、渲染、本地存档、战绩统计
```

纯前端实现，零依赖，可离线运行。
