# 数独 · 单机版

与五子棋单机版同风格的数独小游戏。无需联网、无需安装，双击 `index.html` 即可玩。

## 功能

- **三档难度**：简单（约 40 提示）/ 中等（约 32）/ 困难（约 26），所有题目均为**唯一解**
- **实时冲突校验**：填入与同行/列/宫重复的数字立即标红，并计入错误次数
- **视觉状态区分**：预填固定格（白色粗体）与用户填入格（蓝色）一目了然；选中格高亮 + 同行同宫浅色提示 + 相同数字联动标记
- **计时与错误统计**：实时计时、错误计数，通关后按难度记录胜场与最佳成绩（localStorage）
- **检查答案**：随时核对已填数字，错误处划线标记
- **撤销 / 清空重填 / 暂停 / 新一局**
- **进度自动存档**：中途退出再进可"继续上局"（24 小时内有效）
- **键盘支持**：数字键 1-9 填数、Backspace/0 擦除、方向键移动、Esc 暂停
- **PWA**：手机浏览器打开 https://ln646.github.io/gomoku-online/sudoku/ 点"安装到手机桌面"，之后全屏离线可玩

## 启动方式

双击 `index.html` 用浏览器打开即可；或部署到任意静态托管（本项目无需后端）。
